## Bloom
This project aims to provide an intelligent and supportive space to help users monitor, understand, and improve their mental well-being through smart technology.

## Features
- Automatic mood detection.
- Personalized suggestions through text and audio.
- User-friendly and accessible interface
- Built with modern web technologies for optimal performance

## Live Demo
Try it here 👉 [Click to open the live app](https://diga-diga-8e9k.vercel.app)

## How It Works
1. Chat directly with our AI assistant about mental health topics for personalized advice and tips
2. Take a photo of your face for instant mood analysis and audio feedback
3. Track your daily mood and view progress over time
4. Listen to calming music and guided meditations to improve your mood

## Technologies Used
- Vite
- TypeScript
- React
- Framer Motion
- Tailwind CSS

## AI & Integrations
- Gemini 2.0 Flash
- FaceAPI.js
- ElevenLabs

## 🛠️ Getting Started
1. **Clone the project**
   ```bash
   git clone https://github.com/firas1438/Bloom.git
   cd Bloom
   ```
2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the application**
   ```bash
   npm run dev
   ```
